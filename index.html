GitHub Pages & PWA Install လမ်းညွှန်

ဒီ Web App ကို GitHub Pages ပေါ်တင်ပြီး ဖုန်းထဲမှာ App အဖြစ် Install လုပ်နိုင်ဖို့ အောက်က ဖိုင် ၂ ခုကို Download ဆွဲပြီး index.html နဲ့အတူ တင်ပေးပါ။

GitHub မှာ တင်နည်း (အဆင့်ဆင့်)
  1. GitHub မှာ Repository အသစ်တစ်ခု (Public) ဖန်တီးပါ။
  2. ဒီ HTML ဖိုင်ကို index.html အမည်နဲ့ ထည့်ပါ။
  3. အပေါ်က Download ဆွဲထားတဲ့ manifest.json နဲ့ sw.js ကိုပါ တစ်ခါတည်း Upload တင်ပါ။
  4. Repository > Settings > Pages > Branch ကို main ရွေးပြီး Save နှိပ်ပါ။
  5. ထွက်လာတဲ့ GitHub Pages လင့်ခ်ကို Chrome/Safari နဲ့ဖွင့်ပြီး App Install (သို့) Add to Home Screen နှိပ်သုံးနိုင်ပါပြီ။
